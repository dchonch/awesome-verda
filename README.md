# Awesome Verda [![Awesome](https://awesome.re/badge-flat.svg)](https://github.com/sindresorhus/awesome)

Verda (formerly DataCrunch) is a European AI cloud provider from Helsinki, Finland, offering on-demand GPU instances, clusters, serverless inference, and managed endpoints — powered by 100% renewable energy.
